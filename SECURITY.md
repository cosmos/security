# Cosmos Security Vulnerability Disclosure and Bug Bounty Policy

This policy now lives in the organization's default community health files, so
that every repository in the organization serves it automatically:

https://github.com/cosmos/.github/blob/main/SECURITY.md

Report suspected vulnerabilities through the
[Cosmos Immunefi Bug Bounty Program](https://immunefi.com/bug-bounty/cosmos/information/).
Never open a public issue, pull request, or discussion for a suspected
vulnerability.

This repository remains the home of the security advisories, audits,
communications, and the
[release and maintenance policy](./POLICY.md).
